# Viafoura React Native sample (Expo)

An Expo app that consumes `@viafoura/sdk-react-native` from the package at the
repository root, so it always runs the source in this checkout.

## Requirements

- Node >= 20.19.4 (Expo SDK 54 / React Native 0.81)

## Run

Install and build the package first, from the repository root:

```
npm install
```

Then, in this directory:

```
npm install
npx expo prebuild --clean
npm run ios
npm run android
```

The package contains native code, so Expo Go is not supported; `npm run ios`
and `npm run android` build a development client. `ios/` and `android/` are
generated by prebuild and are not committed.

## Configure

Update the placeholders in `viafouraConfig.ts` with real Viafoura values:

- `siteUUID`
- `siteDomain`
- `containerId`
- `articleUrl`
- `articleTitle`
- `articleThumbnailUrl`
